# Planned benchmark scenarios

These are initial scenario categories for the research prototype. Exact prompts, fixtures, expected outcomes, and scoring rules will be specified later.

1. Straightforward request completion.
2. Request requiring clarification from the user.
3. Multi-step request with dependent actions.
4. Request requiring explicit user confirmation.
5. User cancellation during an active execution.
6. Transient failure followed by retry.
7. Conflicting or changed user instruction during an execution.

All three architectures will receive equivalent inputs through the common execution API.
